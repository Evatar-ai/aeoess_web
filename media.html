Press Kit

Descriptions, key facts, logos, citations, contact. For coverage of AEOESS and the Agent Passport System protocol.

Short description

AEOESS builds the Agent Passport System — an open protocol for AI agent identity, scoped delegation, gateway enforcement, and Merkle-attributed receipts. Apache-2.0 licensed.

Long description

The Agent Passport System (APS) is the open protocol AEOESS develops for AI agents that need to act on behalf of humans, organizations, or other agents. Agents get Ed25519 cryptographic identity. Principals issue scoped delegations that can only narrow at each transfer point. A gateway enforces policy in under two milliseconds across fourteen constraint dimensions and signs every decision with a receipt that anchors back to the originating principal via Merkle attribution.

The protocol describes admissibility, not truth. It accepts did:key, did:web, SPIFFE SVIDs, OAuth tokens, and native did:aps as identity inputs. The SDK ships in TypeScript, MCP server form, and Python. AEOESS contributes to working groups at A2A, AAIF, OWASP AIVSS, OpenSSF, IETF, and the Agent Governance Vocabulary.
