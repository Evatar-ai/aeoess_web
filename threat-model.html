Threat model

What the protocol defends against.

Six adversaries, six concrete blocks. The rest of the document names what is out of scope so operators know where to add controls.

Compromise narrows by design.

Adversary & Cascade

A compromised delegation cannot exceed its scope. A compromised passport revokes the whole subtree at once.

Six classes, six blocks.

Adversaries

A1 — Compromised agent

GOAL Act outside its scope.

BLOCK Four-gate pre-flight rejects out-of-scope intents at the gateway boundary. Cascade revocation kills downstream within one signature check.

A2 — Malicious delegator

GOAL Grant authority it does not hold.

BLOCK Monotonic narrowing: a delegation cannot grant scope its parent did not have. Verifier walks the chain to a registered passport root.

A3 — Replay attacker

GOAL Reuse a signed action.

BLOCK Action receipts include a nonce and a signed timestamp. Custody receipts bind the input set to a Merkle root.

A4 — Phantom issuer

GOAL Inject signals from a non-existent issuer.

BLOCK Vocabulary registry enforces single-source-of-truth. Validators reject signal types lacking a production issuer.

A5 — Drift-prompt injector

GOAL Override the operator instruction mid-session.

BLOCK Instruction Provenance Receipts bind agent authority to a hashed instruction file. Drift across turns is denied at the boundary.

A6 — Downgrade attacker

GOAL Force a weaker auth path.

BLOCK Mutual authentication handshake is downgrade-proof. TrustBundle pins the supported algorithm set.

What we cover, what we do not.

Trust boundary

In scope

  • Cryptographic primitives (Ed25519, RFC 8785)
  • Gateway boundary enforcement
  • Signed receipts and their verification
  • Cascade revocation across the delegation tree
  • Conformance fixtures and adapters

Out of scope

  • Effect safety of the agent (see Paper 8)
  • Correctness of the operator’s policy choices
  • Unsigned out-of-band channels the agent may use
  • Identity-provider compromise upstream of bridging

Effect safety is catalogued separately in Paper 8 (The Evidence-Safety Gap). The protocol specifies procedural validity. We cite our own limits.
