AEOESS

Agentic Economy Orchestration Engine for Sovereign Systems

The agentic economy is here. Your AI agents book flights, write code, manage money, and talk to other agents. There are no rules.

AEOESS is the rulebook. Every agent gets a cryptographic identity. You control exactly what each one can do. Trust is earned through performance. Values compliance is checked at every action. Purchases require approval gates. Every action scoped, auditable, revocable.

Ed25519 identity. Scoped delegation chains with monotonic narrowing. Bayesian reputation. Values floor enforcement. 4-gate agentic commerce. Merkle-proven attribution. W3C DID & Verifiable Credentials. One npm install.
