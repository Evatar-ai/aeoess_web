Quick start

1

Install the SDK

npm install agent-passport-system
2

Set your API key

export AEOESS_API_KEY="aps_live_..."
3

Govern a tool call (pick your framework)

import { governMCPToolCall } from 'agent-passport-system'

const result = await governMCPToolCall(
  { name: 'web_search', arguments: { q: 'test' } },
  async (args) => searchWeb(args.q),
  { passport, delegation, privateKey }
)
// result.receipt is Ed25519-signed proof

Works with LangChain, CrewAI, MCP, A2A, Stripe, Composio, Gonka. See full docs.

4

Check your dashboard

Visit gateway dashboard to see evaluations, trust scores, and audit trails in real time.
